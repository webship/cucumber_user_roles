# Cucumber User Roles - webship-js feature scenarios

| File | Covers |
|------|--------|
| `01-01-01-users-login.feature` | Per-user login; the first scenario provisions the testing users, including one with the Tester role. |
| `02-01-01-cucumber-user-roles-modules-enabled.feature` | Cucumber User Roles and all six role sub-modules are enabled. |
| `03-01-01-user-roles-created.feature` | The six roles exist with their permissions, and each has its own dashboard. |

The six sub-modules must be enabled before the suite runs; see `tests/README.md`.
